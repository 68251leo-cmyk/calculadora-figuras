# Calculadora de áreas
Proyecto en equipo para practicar el flujo de colaboración con Git y GitHub.

## Equipo
- Líder: (nombre)
- Colaborador A: (nombre), triángulo y rectángulo
- Colaborador B: (nombre), círculo y hexágono

## Instalación
1. Crear y activar el entorno virtual.
2. Ejecutar: pip install -r requirements.txt
3. Ejecutar: python main.py

## Lista de revisión de un Pull Request
- El Pull Request agrega un solo archivo, dentro de figuras/.
- El archivo y la función tienen el nombre acordado.
- La función rechaza valores menores o iguales a cero con ValueError.
- El mensaje del commit explica qué se hizo.
